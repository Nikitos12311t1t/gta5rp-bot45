# GTA5RP Перекуп Калькулятор Bot

Telegram-бот для GTA 5 RP:
- калькулятор прибыли
- история сделок
- статистика
- SQLite база
- красивое меню

## Установка

1. Установи Python 3.11+
2. Установи зависимости:

pip install -r requirements.txt

3. Создай `.env`
4. Вставь токен Telegram-бота:

BOT_TOKEN=YOUR_TOKEN

5. Запуск:

python main.py

## Команды

/start
/calc
/history
/stats
/help
